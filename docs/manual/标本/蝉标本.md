# 蝉标本

酒精浸泡 10h，发黑，推测是多酚酶促氧化褐变。
酒精+焦亚硫酸钠浸泡 5h，干燥过程中绿色能维持，翅膀浸泡后褪色发黄，干燥后绿色逐渐发黄。
酒精+焦亚硫酸钠+抗坏血酸钠+EDTA，干燥中就开始发黄，抗坏血酸钠和 EDTA 负效果，怀疑抗坏血酸钠氧化发黄。

调研发现抗坏血酸钠 本身就会发棕，不可取。

用硫酸锌+冰醋酸（柠檬酸粘稠）保绿+焦亚硫酸钠防止褐变，浸泡 3h，时间短，效果不明显。

EDTA 无法螯合多酚氧化酶的铜，几乎无效。

4-己基间苯二酚 是酪氨酸酶抑制剂。

低 ph 可以部分抑制酪氨酸酶活性。

接下来尝试 酒精 20ml+冰醋酸 5ml，4-己基间苯二酚，浸泡 5h，看效果。
